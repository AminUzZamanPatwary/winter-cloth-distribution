🟦 Winter Cloth Distribution System
📌 Project Description

This is a web-based system built using PHP and MySQL to manage winter cloth donation, requests, and distribution between admin, donors, and recipients.

🟢 Requirements

To run this project, you need:

XAMPP (Apache + MySQL)
Web browser (Chrome recommended)
PHP enabled (inside XAMPP)
🟢 Installation & Setup Guide
1. Download the project

Download or clone this repository:

git clone https://github.com/AminUzZamanPatwary/winter-cloth-distribution.git
2. Move project to XAMPP folder

Move the folder to:

D:\xampp\htdocs\

Rename if needed:

Winter_Cloth_Management
3. Start XAMPP

Open XAMPP Control Panel and start:

Apache ✔
MySQL ✔
4. Import database
Open browser
Go to:
http://localhost/phpmyadmin
Create a database:
winterclothdistribution
Click Import
Select:
database.sql
Click Go
5. Run the project

Open your browser and go to:

http://localhost/Winter_Cloth_Management/
